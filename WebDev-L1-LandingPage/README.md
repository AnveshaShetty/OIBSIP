# 🎵 MelodyX — Music Streaming Landing Page

> **Your sound, finally unmuted.**

MelodyX is a modern, responsive landing page concept for a fictional music streaming platform. It is designed around a premium dark interface, vibrant gradients, smooth interactions, and a listener-focused experience.

This project was created as part of the **Oasis Infobyte Web Development & Designing Internship — Level 1, Task 1: Landing Page**.

---

## 🌐 Live Demo 

🔗 **Live Website:** https://melodyx-where-beats-finds-you.netlify.app


---

## 📌 About the Project

MelodyX is a fictional music streaming platform designed for listeners who want high-quality audio, personalized playlists, offline listening, podcasts and a clean user experience.

The landing page focuses on:

- Modern visual design
- Responsive layouts
- Clear content hierarchy
- Interactive hover effects
- Premium music-streaming aesthetics
- Accessible and semantic HTML

## 🎨 Design

The project uses a dark, futuristic music-streaming aesthetic.

### Color Palette

- Deep Black / Purple
- Violet
- Pink
- Cyan
- Green

Gradients are used throughout the interface to create a vibrant music-focused visual identity.

### Typography

The project uses Google Fonts:

- **Unbounded** — Display headings and branding
- **Plus Jakarta Sans** — Body text and UI elements

---

## 📱 Responsive Design

The website is designed to work across:

- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile

CSS Grid, Flexbox, responsive breakpoints and fluid sizing are used to adapt the layout to different screen sizes.
